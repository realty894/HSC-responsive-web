# 🔬 한화 사이언스 챌린지(HSC) 반응형 웹 구축

> 기업 캠페인/공모전 웹사이트를 분석하여 시맨틱 레이아웃과 모바일 환경에 특화된 인터페이스 전환을 구현한 반응형 웹 퍼블리싱 프로젝트입니다.

- **작업 기간**: 약 5일
- **기여도**: 개인 작업 100%
- **배포 링크**: [🔗 한화 사이언스 챌린지 웹사이트 바로가기](https://realty894.dothome.co.kr/work/HSC)

---

## 🛠 Tech Stack
- **Markup**: HTML5 (시맨틱 태그 구조화, 스크린 리더 접근성)
- **Styling**: CSS3 (Flexbox 레이아웃, 미디어 쿼리 기반 반응형)
- **Design & Assets**: XEIcon, Nanum Gothic Web Font

---

## 📌 핵심 퍼블리싱 역량

### 1. 웹 표준 준수 및 시맨틱 레이아웃
- `div` 태그 남발을 지양하고 `header`, `section`, `article`, `nav`, `footer` 태그를 목적에 맞게 분할해 정보 계층 구조를 명확히 설계했습니다.
- 화면에는 보이지 않지만 스크린 리더가 문서 개요를 읽을 수 있도록 숨김 제목(`.blind`)을 배치하여 웹 접근성 기본 원칙을 충실히 지켰습니다.

### 2. 디바이스 특화 인터페이스 전환
- 데스크톱의 가로 5열 연도별 수상작 탭 메뉴를 모바일 뷰포트(800px 이하)에서는 좌우 화살표 버튼 기반의 단일 연도 전환 UI로 재구성하여 터치 접근성을 높였습니다.
- 공지사항, FAQ, 운영사무국으로 이어지는 3열 수평 그리드 레이아웃을 모바일 화면에 맞춰 가독성 높은 직관적인 세로 카드 형태로 최적화했습니다.

## 💡 배운 점 및 성장

- **모바일 UX 관점의 UI 재설계**: 단순히 화면 크기만 줄이는 반응형을 넘어, 뷰포트 환경과 사용자 조작 편의성을 고려해 컴포넌트의 형태와 배치를 능동적으로 재설계하는 퍼블리싱의 기초를 확립한 프로젝트입니다.
